# Проверка подключения CarLink RU v6 на TEYES TPRO 2

Статус: экспериментальная интеграция. Наличие APK **не означает**, что CarPlay и AirPlay работают на магнитоле.

## 1. CarPlay

TEYES прямо указывает, что TPRO 2 не имеет штатной поддержки CarPlay.
Для такой модели производитель рекомендует внешний CarPlay-адаптер:

- https://www.teyes.pro/blogs/blog/teyes-tpro-2
- https://www.teyes.eu/pages/faqs

Дополнительно сборка исходного CarLink в GitHub **не содержит** данных
аутентификации CarPlay-аксессуара. Эти данные нельзя сгенерировать из
Bluetooth-сопряжения или взять из несуществующего файла.
Для штатной работы нужен авторизованный совместимый способ подключения.

Если беспроводное соединение останавливается на Bluetooth, проверьте,
есть ли в головном устройстве отдельный Bluetooth-модуль, доступный только
прошивке. Это отдельное ограничение для некоторых FYT-устройств.

Не устанавливайте случайные APK со встроенными приватными ключами.

## 2. AirPlay — диагностика

1. Подключите iPhone и TEYES к **одной обычной сети Wi-Fi**. Не используйте
   гостевую сеть с изоляцией клиентов. Включение Bluetooth для AirPlay не требуется.
2. Откройте CarLink RU → AirPlay. Вверху должен отображаться запущенный сервер.
   При остановке вручную нажмите Start.
3. Откройте вкладку **Logs / Логи**. Новые сборки записывают:
   - `Сеть для AirPlay: Wi-Fi=true/false, IP=...`
   - `Server started on port 7000` (порт может отличаться)
   - `mDNS: AirPlay registered: ...` или `mDNS: AirPlay registration failed: ...`
   - `AirPlay native library error: ...` (если нативная библиотека не загрузилась)
4. На iPhone выберите Пункт управления → Повтор экрана.
   Если имя приёмника не появилось — это проблема обнаружения или Wi-Fi.
   Если имя есть, но подключение не завершается — изучите логи после попытки.
5. В AirPlay → Logs нажмите **Export**, отправьте текст лога для анализа.
   Если экспорта нет, сфотографируйте последние 20 строк.

CarLink → Настройки → Общие → Диагностика → Поделиться журналом
позволяет получить отдельный лог CarPlay.

## 3. Что проверено автоматически

GitHub Actions собирает единый debug APK и проверяет наличие
`libairplay_native.so`, компонентов AndroidManifest и хеша APK.

Это **не проверяет** handshake iPhone, AirPlay mDNS на TEYES и CarPlay
с авторизованным аксессуаром. Для таких проверок нужны реальные логи
и физическое устройство.
